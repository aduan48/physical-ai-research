# Physical AI Opportunities Near Colby College

Where can robots, drones, computer vision, and smart sensors fix real bottlenecks in industries around Waterville, Maine? This project answers that one industry at a time, with sources for every claim.

**Status:** 1 of 9 industries done (Forestry). See [PROGRESS.md](PROGRESS.md).
